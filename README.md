# PT Krakatau Indah — Sistem Informasi Manajemen

Monorepo berisi tiga aplikasi untuk PT Krakatau Indah (proyek Kerja Praktik / Tugas Akhir):

- **[admin-web](admin-web/)** — Dashboard admin berbasis React + Vite + Supabase: manajemen proyek, karyawan, presensi, penggajian, inventaris, dan laporan.
- **[mandor_app](mandor_app/)** — Aplikasi mobile Flutter untuk mandor lapangan: presensi, lembur, kasbon, dan permintaan barang.
- **[sistem_cerdas_app](sistem_cerdas_app/)** — Aplikasi mobile Flutter untuk prediksi kebutuhan material dan deteksi anomali data kepegawaian (Tugas Akhir).

Setiap folder memiliki README dan instruksi setup (dependensi, environment, migrasi Supabase) masing-masing.
